강동자바라 스텐 난간대 견적기 v1.1
=================================

1. 사용하기
- index.html을 브라우저로 열면 바로 사용할 수 있습니다.
- 인터넷 API/Supabase 연결은 없습니다.
- 기존 일정관리 프로그램(kd-factory-photo)과 다른 프로그램입니다.

2. 계산 기준
- 단가는 '난간대 길이 1m' 기준입니다.
- 높이 1000mm : SUS201 37,000원 / SUS304 47,000원
- 높이 1200mm : SUS201 39,400원 / SUS304 51,400원
- 기준가 : 높이 1000mm + SUS201 / 1m = 37,000원
- 옵션 차액 : H1000 SUS201 +0원 / H1000 SUS304 +10,000원 / H1200 SUS201 +2,400원 / H1200 SUS304 +14,400원
- 파이프 두께: 0.9T (기본 고정)
- 끝기둥 추가: 1개 15,000원
- 중간기둥 추가: 1개 15,000원
- 길이: 1m, 2m, 3m 등 정수 단위만 적용
- 수량은 동일 제품의 수량입니다.
- 총액 = [(1m 단가 × 길이 m) + (끝기둥 수 + 중간기둥 수) × 15,000원 + 기타 추가금] × 수량
- 부가세 10% 체크 시에만 위 총액에 VAT가 추가됩니다.
  ※ 원본 사진의 가격이 부가세 포함인지 여부는 미확인입니다.
- 배송비/설치비는 견적에 포함되지 않습니다.

3. 견적 목록
- 여러 건을 추가하여 합계를 계산하고, 복사/인쇄할 수 있습니다.
- 목록은 현재 브라우저 localStorage에 저장됩니다.
- GitHub에 게시하더라도 다른 사람의 브라우저와 내용이 공유되지 않습니다.
- 데이터 보존을 위해 '견적 목록 백업(JSON)'을 이용해 주기적으로 백업하세요.

4. GitHub Pages 배포 방법
- 'kd-rail-estimate' 같은 새 저장소를 권장합니다.
- index.html, app.js, style.css, assets 폴더를 저장소의 최상위에 업로드합니다.
- Settings > Pages > Deploy from a branch > main / (root)을 선택합니다.
- 기존 kd-factory-photo 저장소에 올리면 개인용 촬영 스케줄을 덮어쓸 수 있습니다.

5. 미적용 항목
- 첨부 사진에 있는 '4T 8,000원' 항목은 적용 대상이 명확하지 않아 기본 계산에 자동 포함하지 않았습니다.
  필요하다면 '기타 추가금'에 직접 입력할 수 있습니다.

6. v1.1 업데이트 유의사항
- 기존에 브라우저에 저장된 견적 목록은 유지되지만, 화면에서 새 단가로 다시 계산됩니다.
- 오래된 단가로 작성한 견적을 보관하려면 업데이트 전에 견적 목록을 별도로 백업/저장하세요.
- 카페24 상품 기본가격 37,000원, 옵션 차액은 위 값으로 입력하시면 됩니다.
